# 微信小程序 UI 设计自检清单

## P0 — 必须通过

- [ ] **无 :root 外的 hex 色值。** 所有颜色使用 CSS 变量。
- [ ] **使用 seed 中已定义的 class。** 不自创全局 class。
- [ ] **无 emoji 图标。** 使用 SVG 或 cell-icon class。
- [ ] **无占位文字。** 所有 `[REPLACE]` 已替换。
- [ ] **微信导航栏正确。** 使用 wx-navbar + wx-capsule，不用自定义导航。
- [ ] **胶囊按钮位置正确。** 右上角，不被内容遮挡。
- [ ] **accent 每屏最多 2 次。** 主按钮 + 一个强调元素。
- [ ] **触摸目标 ≥ 44px。** 所有可点击元素最小高度 44px。
- [ ] **单屏单任务。** 一个页面只做一件事，不混合多个功能。

## P1 — 应该通过

- [ ] **WeUI 面板风格。** 列表用 wx-panel 包裹，圆角白色背景。
- [ ] **section-gap 分隔。** 不同功能区域用 8px 灰色间隔分开。
- [ ] **数字用 .num class。** 价格、统计、数量。
- [ ] **列表项有箭头。** 可跳转的 cell 带 cell-arrow。
- [ ] **底部安全区。** 固定底部操作栏不被 home indicator 遮挡。
- [ ] **头像用方形圆角。** 微信风格头像是 4px 圆角方形，不是圆形。

## P2 — 加分项

- [ ] **有真实感数据。** 不是"功能一/功能二"，而是具体的商品名、价格、用户名。
- [ ] **宫格图标用 SVG。** 不是纯色方块。
- [ ] **状态标签有颜色区分。** 待付款/待发货/已完成用不同颜色 tag。

## 微信小程序特有规则

- 导航栏高度固定 44px，不可自定义高度
- 胶囊按钮是系统组件，不可隐藏或移动
- 页面背景色用 var(--bg)（#EDEDED），不用纯白
- 返回按钮只在非首页出现（首页用 wx-navbar-title 居中）
- 分享功能通过 wx-share 面板实现，不用自定义弹窗
