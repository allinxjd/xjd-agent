# 移动端 UI 设计自检清单

对照检查后再输出。P0 = 必须通过；P1 = 应该通过；P2 = 加分项。

## P0 — 必须通过

- [ ] **无 :root 外的 hex 色值。** 所有颜色使用 `var(--bg)` / `var(--fg)` / `var(--accent)` / `var(--muted)` / `var(--border)` / `var(--surface)` 或 `color-mix()`。
- [ ] **accent 最多出现 2 次。** 计数：主操作按钮 + 一个强调元素。超过则降级为 `var(--fg)` 或 `var(--muted)`。
- [ ] **使用 seed 中已定义的 class。** 不自创 class，不写 inline style（除非调整间距）。
- [ ] **手机框架完整。** Dynamic Island、状态栏、Home Indicator 保持不动。
- [ ] **单屏单任务。** 不混合多个原型（Feed+Checkout+Profile 混在一起 = 不合格）。
- [ ] **点击区域 ≥ 44px。** 所有可交互元素最小高度 44px。
- [ ] **无占位文字。** 所有 `[REPLACE]` 已替换为具体内容。无 lorem ipsum。
- [ ] **无 emoji 图标。** 使用 SVG 或 class 定义的图标样式。
- [ ] **交互状态完整。** 按钮有 hover/active/disabled 三态；输入框有 focus/error 态。

## P1 — 应该通过

- [ ] **数字用 `.num` class。** 价格、统计、日期等数字内容。
- [ ] **列表项有真实数据。** 不是 "项目1/项目2/项目3"，而是具体的名称和描述。
- [ ] **视觉层级清晰。** 标题 > 正文 > 说明文字，字号递减。
- [ ] **留白节奏一致。** section-gap 统一 8px，pad 统一 16px。
- [ ] **Tab Bar 图标有区分。** 不是 4 个一样的圆形。
- [ ] **空状态设计。** 列表为空时有引导文案和插图。
- [ ] **加载状态设计。** 用 `.skeleton` class 展示骨架屏。
- [ ] **导航高亮。** 当前 Tab 有 active 样式区分。

## P2 — 加分项

- [ ] **有一个微妙的设计亮点。** 一个精心设计的卡片、一个有意义的数据展示。
- [ ] **微交互动画。** 卡片点击缩放、列表下拉刷新、页面切换过渡。
- [ ] **手势提示。** 可滑动区域有视觉暗示（如露出半个卡片）。

## 交互设计规范

每个页面必须包含以下交互说明（用 HTML 注释 `<!-- interaction: ... -->` 标注）：

- **按钮交互**: active 按下效果、disabled 灰色不可点击、loading 态
- **表单交互**: focus 边框高亮、校验失败提示、提交中状态
- **列表交互**: 空状态展示、下拉刷新、上拉加载更多
- **导航交互**: Tab 切换动画、页面返回手势
- **反馈交互**: toast 提示、底部弹窗确认
